# Surma Tersoo — Personal Portfolio

A plain, duotone personal portfolio for **Surma Tersoo**, Software Engineering Student at **Veritas University, Abuja**.

Designed with an understated editorial aesthetic inspired by personal developer websites: zero glowing gradients, zero artificial cards or stock badges, strict duotone typography, and direct contact details.

---

## 📄 Overview

- **Design Philosophy**: Minimal, unpretentious, human.
- **Palette**: Strict duotone monochrome (Ink & Paper) with seamless light/dark mode support.
- **Typography**: Clean system stack + Inter and JetBrains Mono.
- **Zero Build Requirement**: Runs immediately in any browser by opening `index.html`.
